# A-certic.com

Página temporária exibindo somente a imagem original fornecida pelo cliente, sem efeitos ou conteúdo adicional. A arte é preservada inteira, sem recorte ou distorção; telas com proporção diferente podem apresentar espaço ao redor.

## Netlify

Branch `main`. Build command vazio. Publish directory `public`. Configuração definida em `netlify.toml`.

## Atualizar

Substitua `public/assets/em-construcao.png` para trocar a arte. O HTML tem descrição alternativa para leitores de tela. Não carrega os antigos arquivos CSS, JavaScript ou a marca vetorial.
